Overview

The Bar Numbering indicator is a simple, focused tool for futures traders who need to track bar counts with session context. Built specifically for ES, NQ, MES, and MNQ futures, it labels every bar with a sequential number and distinguishes between Regular Trading Hours (RTH) and Electronic Trading Hours (ETH).

This indicator provides clear, objective structure to your chart, helping you reference specific bars in your trading notes and analysis without ambiguity.

What It Does

  • Counts Bars Sequentially – Each bar in the current RTH session gets a number (1, 2, 3…).
  • Resets at RTH Open – The count resets to 1 at the start of each new RTH session (9:30 AM ET).
  • ETH Bars are Prefixed with "E" – Bars outside RTH are labelled E1, E2, E3… so you always know when price is trading in the overnight session.
  • Customizable Display – Choose which bars to label (every 1st, 2nd, 5th, or 10th bar) and where to place the labels (above or below the bar).
  • No Repaint – The indicator draws labels on the current bar as it forms, and does not change past labels. No repaint, no look-ahead bias.

How to Use It

  1. For Journaling – When reviewing your trades, you can reference specific bars (e.g., "At bar 34 of the RTH session, price broke the opening range").
  2. For Session Context – The E prefix instantly tells you if price action occurred during the overnight session (ETH) or the regular session (RTH).
  3. For Pattern Recognition – Track how many bars have formed since the open, which can help you identify time-based patterns (e.g., "The trend usually exhausts around bar 40–50").

Full Pine Script

Copy the code below and paste it into a new TradingView indicator.

//@version=6 // ╔═══════════════════════════════════════════════════════════════════════╗ // ║ BAR NUMBERING — RTH/ETH Bar Counter for Futures ║ // ║ TRACK EVERY BAR WITH CONTEXT. NO REPAINTS. NO BLOAT. ║ // ╚═══════════════════════════════════════════════════════════════════════╝ indicator("SireMammat · Bar Numbering", shorttitle="Sire · Bar #", overlay=true, max_labels_count=500) // ───────────────────────────────────────────── // 🧰 INPUTS // ───────────────────────────────────────────── G_BARNUM = '🔢 Bar Numbers' float labelOffset = input.float(0.5, "Label & Bar Number Offset (x ATR)", minval=0, step=0.1, group=G_BARNUM) float _atr14 = ta.atr(14) float _labelOff = labelOffset * nz(_atr14, 1.0) bool showBarNums = input.bool(true, "Show Bar Numbers", group=G_BARNUM) int barNumFreq = input.int(1, "Show Every Nth Bar", minval=1, maxval=10, group=G_BARNUM, tooltip="1 = every bar, 2 = every other bar, etc.") string barNumPos = input.string("Below Bar", "Label Position", options=["Below Bar","Above Bar"], group=G_BARNUM) string barNumSize = input.string("Tiny", "Label Size", options=["Tiny","Small","Normal"], group=G_BARNUM) color barNumRTHColor = input.color(color.new(color.white, 30), "RTH Number Color", group=G_BARNUM) color barNumETHColor = input.color(color.new(color.gray, 30), "ETH Number Color", group=G_BARNUM) string barNumScope = input.string("RTH + ETH", "Show Numbers For", options=["RTH + ETH","RTH Only","ETH Only"], group=G_BARNUM, tooltip="Choose whether to display bar numbers during RTH, ETH, or both.") // ───────────────────────────────────────────── // 📍 CORE LOGIC // ───────────────────────────────────────────── // TIME CONTEXT (NY TIME) int nyHour = hour(time, "America/New_York") int nyMinute = minute(time, "America/New_York") int nyTime = nyHour * 100 + nyMinute // BAR NUMBER COUNTING var int barCount = 0 var bool wasRTHBar = false // RTH = Regular Trading Hours (9:30 AM - 4:00 PM ET) bool isRTHBar = nyTime >= 930 and nyTime < 1600 if isRTHBar and not wasRTHBar barCount := 1 wasRTHBar := true else if not isRTHBar and wasRTHBar barCount := 1 wasRTHBar := false else barCount += 1 // SIZE CONVERSION _barNumSize = switch barNumSize "Tiny" => size.tiny "Small" => size.small "Normal" => size.normal => size.tiny // VISIBILITY CHECKS bool showThisBar = showBarNums showThisBar := showThisBar and (barCount % barNumFreq == 0 or barCount == 1) if barNumScope == "RTH Only" and not isRTHBar showThisBar := false if barNumScope == "ETH Only" and isRTHBar showThisBar := false // DRAW BAR NUMBER LABELS string barNumText = (isRTHBar ? "" : "E") + str.tostring(barCount) color barNumClr = isRTHBar ? barNumRTHColor : barNumETHColor if showThisBar string _barNumStyle = barNumPos == "Below Bar" ? label.style_label_up : label.style_label_down float _barNumY = barNumPos == "Below Bar" ? low - _labelOff : high + _labelOff label.new(bar_index, _barNumY, barNumText, style=_barNumStyle, color=color.new(color.black, 100), textcolor=barNumClr, size=_barNumSize)
