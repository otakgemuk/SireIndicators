# SireIndicators Dashboard

**Production-ready Next.js 15 trading dashboard**

## Quick Start

```bash
cd frontend
npm install
npm run dev
```

Visit: http://localhost:3000

## Deploy

```bash
npm run build && vercel
```

## Features

✅ Real-time ORB & Raschke signals  
✅ Dark/Light theme  
✅ TypeScript + React 19  
✅ Tailwind CSS v4  
✅ Zustand state management
